# Onboarding

When a new user signs up they land on the dashboard. The dashboard shows three quickstart cards: import markdown, paste a note, or connect an Obsidian vault.

## First-run tutorial

The first time you ask a question, the assistant returns a short answer with inline [^c1] citation markers. Each marker links to the source chunk below the assistant message.

## Tips

- Drag and drop .md files anywhere in the window to import them.
- Use the Filter button in the sidebar to restrict retrieval to a subset of notes.
- The system prompt instructs the model to say "I don't have that in your notes." when no chunks support the answer.
